## Kitabxana: next-intl 4

`apps/web` (Next.js App Router). Qurulum faylları (`src/i18n/`):

- **`routing.ts`** — `defineRouting` (locale-lər + default).
- **`navigation.ts`** — `createNavigation` wrapper-ləri (`Link`, `useRouter`, `usePathname`).
- **`request.ts`** — `getRequestConfig`, hər sorğuda locale-ə uyğun mesajları yükləyir.
- **`proxy.ts`** (kök `src/`) — locale middleware. **Qeyd:** Next.js 16-da `middleware.ts` → `proxy.ts` adlanır.

Tərcümələr: `src/messages/{az,en,ru}.json` — açar-əsaslı. Hər 3 dildə eyni 8 namespace: `nav`, `home`, `projects`, `contact`, `common`, `about`, `blog`, `consent`.

## Routing modeli

Locale-prefiksli (`/az`, `/en`, `/ru`). Default locale də prefikslənir — konsistentlik üçün açıq prefiks. `[locale]` App Router segment-i.

## Fallback

Naməlum/dəstəklənməyən locale → `hasLocale` yoxlaması → default (`az`) və ya `notFound()`. `request.ts`-də əskik locale default-a düşür.

## Static rendering

`generateStaticParams` hər locale üçün səhifələri build-də generasiya edir (SSG). `setRequestLocale(locale)` next-intl API-lərindən əvvəl çağırılır (static rendering üçün tələb).

## Kontent tərcüməsi (gələcək)

Hazırda **UI mətnləri** tərcümə olunur (mesaj JSON-ları). **Kontent** (project/service başlıq/təsvir) hələ tək dildədir — DB-də multi-lang sahələr (məs. `title_az`, `title_en`) lazım olarsa, schema genişləndiriləcək və burada qeyd olunacaq. İndilik YAGNI.
